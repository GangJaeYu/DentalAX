# AI(LLM) API 쉽게 이해하기

> 원장님·실장님을 위한 설명서입니다. 코딩을 몰라도 읽을 수 있게 썼습니다.
> 확인일: 2026-10-16. 화면 구성이나 가격은 각 회사 사정에 따라 바뀔 수 있습니다.

## 1. LLM API가 뭔가요? — "전화로 부르는 글쓰기 전문가"

- **LLM**(거대 언어 모델)은 ChatGPT, Claude, Gemini 같은 "글을 이해하고 쓰는 AI"입니다.
- 평소 쓰는 채팅 앱(웹사이트)은 **사람이 직접 들어가서 대화하는 창구**입니다.
- **API**는 **프로그램이 AI 회사에 직접 전화를 거는 전용 회선**입니다. DentalAX가 이 회선으로 "이 메모를 공지로 다듬어 줘"라고 부탁하고, 답을 받아 화면에 보여 줍니다.
- 비유하자면, 채팅 앱은 "월정액 뷔페", API는 "먹은 만큼 내는 단품 주문"입니다. 원내 업무처럼 짧은 글을 가끔 쓰는 용도라면 API가 훨씬 저렴한 경우가 많습니다.

## 2. API 키가 뭔가요? — "우리 병원 전용 법인카드"

- API 키는 `sk-ant-...`, `sk-...`, `AIza...` 처럼 생긴 긴 문자열입니다.
- 이 키로 부른 AI 사용료는 **키 주인(병원) 계정으로 청구**됩니다. 그래서 **카드 번호처럼 관리**해야 합니다.
- DentalAX는 키를 **서버 PC 안에 암호화해서 저장**하고, 직원 PC·태블릿의 브라우저로는 **절대 보내지 않습니다.** 화면에는 끝 4자리만 보입니다.

## 3. 키 발급 방법 (셋 중 하나만 있으면 됩니다)

> 공통: 회원가입 → 결제 수단 등록(선불 충전 또는 카드) → API 키 만들기 → 키 복사 → DentalAX **관리 → AI 설정 → API 키**에 붙여넣기 → **연결 테스트**.
> 키는 만들 때 **한 번만** 전체가 보입니다. 바로 DentalAX에 붙여넣고, 다른 곳(메모장, 카톡)에 남기지 마세요.

### Anthropic Claude (추천)
1. https://platform.claude.com 접속 → 회원가입(이메일 또는 구글 계정).
2. 왼쪽 메뉴 **Billing(결제)** → 카드 등록 후 **크레딧 충전**(예: 10달러). 선불 방식이라 충전한 만큼만 쓰입니다.
3. **Settings → API keys** (https://platform.claude.com/settings/keys) → **Create Key** → 이름(예: `dentalax`) 입력 → 생성된 `sk-ant-...` 키 복사.
4. DentalAX: 관리 → AI 설정 → "Anthropic Claude" 칸에 붙여넣기 → **저장** → **연결 테스트** → 위쪽 "AI 공급자"에서 **Anthropic Claude** 선택 → **AI 설정 저장**.

### OpenAI
1. https://platform.openai.com 접속 → 회원가입.
2. **Settings → Billing** → 결제 수단 등록 및 크레딧 충전.
3. **API keys** (https://platform.openai.com/api-keys) → **Create new secret key** → `sk-...` 키 복사.
4. DentalAX에서 "OpenAI" 칸에 저장 → 연결 테스트 → 공급자 OpenAI 선택 → 저장.

### Google Gemini
1. https://aistudio.google.com 접속 → 구글 계정 로그인.
2. **Get API key** (https://aistudio.google.com/apikey) → 키 만들기 → `AIza...` 복사.
3. ⚠️ **반드시 결제(유료 등급)를 켜고 쓰세요.** 무료 등급은 입력 내용이 Google 제품 개선에 쓰이고 사람이 검토할 수 있다고 약관에 적혀 있습니다(아래 6절).
4. DentalAX에서 "Google Gemini" 칸에 저장 → 연결 테스트 → 공급자 선택 → 저장.

## 4. 토큰과 요금 — "글자 수로 내는 요금"

- AI 요금은 **토큰** 단위로 매깁니다. 토큰은 글을 잘게 자른 조각입니다. 한국어는 대략 **글자 1개 ≈ 토큰 1~1.5개**로 생각하면 됩니다.
- 요금은 두 가지입니다.
  - **입력(보내는 글)**: 우리가 보낸 지시문 + 메모 + (도우미의 경우) 찾아 붙인 원내 문서
  - **출력(받는 글)**: AI가 써 준 답. **출력 단가가 입력보다 4~5배 비쌉니다.**
- 가격은 "1백만 토큰당 몇 달러"로 표시합니다. 예) 입력 $0.1 / 출력 $0.5 (1백만 토큰당)
- 예시: 공지 다듬기 1회 = 입력 약 700토큰 + 출력 약 400토큰 → 저가 모델 기준 **약 0.4원**.
- 같은 질문도 **모델 등급**에 따라 값이 20~40배 차이 납니다. DentalAX는 기능마다 "빠른 모델(저가)"과 "상위 모델"을 나눠 씁니다(관리 → AI 설정 → 기능별 모델 등급).
- 이번 달 사용액은 **관리 → AI 사용량**에서 원 단위로 볼 수 있고, **월 예산**을 넘으면 자동으로 멈춥니다(설정 가능).
- 자세한 비용 계산은 [COST.md](COST.md)를 보세요.

## 5. 키 관리 안전 수칙 (꼭 지켜 주세요)

1. **키는 DentalAX 관리 화면에만 넣습니다.** 카톡·문자·이메일·메모장·포스트잇에 적지 않습니다.
2. **AI 회사 사이트에서도 한도를 겁니다.** 각 회사 결제 화면에서 "월 사용 한도(spending limit)" 또는 "자동 충전 끄기"를 설정하면 이중 안전장치가 됩니다.
3. **선불 충전 방식**을 쓰면 키가 새어 나가도 충전한 금액 이상은 쓰이지 않습니다.
4. 직원이 퇴사하거나 키가 노출된 것 같으면: AI 회사 사이트에서 **그 키를 삭제(Revoke)** → 새 키를 만들어 DentalAX에 다시 저장합니다.
5. API 키 계정의 비밀번호는 다른 사이트와 다르게, 가능하면 **2단계 인증**을 켭니다.
6. 다른 PC로 백업을 복원하면 키는 옮겨지지 않습니다(암호화 열쇠가 PC마다 다름). 관리 화면에서 다시 입력하세요.

## 6. 데이터는 어떻게 다뤄지나요? (API 기준, 2026-10-16 확인)

| 항목 | Anthropic | OpenAI | Google Gemini |
|---|---|---|---|
| 입력을 AI 학습에 쓰나 | 기본적으로 쓰지 않음 | 기본적으로 쓰지 않음 | **무료 등급은 씀**(사람 검토 가능) / 유료 등급은 쓰지 않음 |
| 보관 기간 | 30일 이내 자동 삭제(정책 위반 의심 시 더 길게) | 남용 감시 기록 최대 30일 | 남용 감시용 55일 |
| 보관 안 함(ZDR) | 영업팀 계약 시 가능 | 사전 승인 시 가능 | Developer API에선 사실상 미제공(Vertex AI 필요) |

출처: Anthropic https://platform.claude.com/docs/en/manage-claude/api-and-data-retention · OpenAI https://developers.openai.com/api/docs/guides/your-data · Google https://ai.google.dev/gemini-api/terms

**그래서 DentalAX는** ① 환자 정보를 애초에 입력·저장하지 않게 만들었고, ② 보내기 전에 서버에서 주민번호·전화번호·이메일·카드·계좌·차트번호·"OOO 환자" 같은 표기를 찾아 가리거나 막으며, ③ AI 입력창마다 "환자 개인정보 입력 금지" 안내를 띄웁니다.
그래도 **자유 입력 글에 환자 이야기를 쓰지 않는 습관**이 가장 확실한 보호입니다.

> 이 문서는 일반적인 안내이며 법률 자문이 아닙니다. 개인정보보호법상 국외 이전 고지·동의 등 구체적 판단은 전문가와 상의하세요.

## 7. 자주 묻는 질문

- **Q. 키 없이도 쓸 수 있나요?** 네. "데모 모드"로 모든 화면과 흐름이 동작하고, AI 부분은 예시 응답이 나옵니다. 원내 AI 도우미는 데모 모드에서도 관련 문단을 찾아 보여 줍니다.
- **Q. 어느 회사가 좋나요?** [COST.md](COST.md)의 추천을 보세요. 기본 추천은 Anthropic Claude(저가 Haiku + 문서용 Sonnet)입니다.
- **Q. 인터넷이 끊기면?** AI 기능만 "연결하지 못했습니다" 안내가 뜨고, 나머지(재고·근무표 등)는 원내망에서 그대로 동작합니다.
- **Q. 응답이 늦어요.** 긴 문서는 20~60초 걸릴 수 있습니다. 60초(설정 가능)가 넘으면 자동으로 중단하고 알려 줍니다.
