# 이 프로젝트는 어떻게 만들어졌나 (BUILD STORY)

> 처음으로 → [README](../README.md)

## 왜 만들었나

치과에서 진료 외 업무(데스크·행정·서류·재고 등)를 AI로 덜어 보려는 시도가 늘고 있지만, "개발자가 있어야 가능하다"는 생각에 시작조차 어려운 경우가 많습니다.
이 프로젝트는 **코딩을 전혀 모르는 치과의사도 AI 코딩 도구에 잘 정리된 프롬프트 하나만 주면 원내에서 바로 쓸 수 있는 서비스를 얻을 수 있는지** 확인하기 위한 실험이자 예시입니다.

## 조건 — "순수한 체급"으로만

| 항목 | 내용 |
|---|---|
| 도구 | Claude Code |
| 모델 | **Claude Opus 5.5**, 추론 강도(effort) **high** |
| 입력 | **프롬프트 한 번** ([② 확장 프롬프트](prompts/2-expanded-prompt.md)를 새 세션에 그대로 붙여 넣음) |
| 외부 확장 | PC에 외부 플러그인·MCP 서버(Notion, Hugging Face 등)·스킬이 설치되어 있었지만 **하나도 사용하지 않음** (프롬프트 규칙 1번) |
| 쓴 기능 | Claude Code 기본 도구만: 파일 읽기·쓰기, 터미널, 코드 검색, 하위 에이전트, 웹 검색·웹 페이지 읽기 |
| 사람의 개입 | **개발 중 질문·선택·승인 0회.** 결정이 필요한 곳은 AI가 기본값을 고르고 이유를 [DECISIONS.md](DECISIONS.md)에 기록 |
| 작업 PC | Windows 11, Node.js 24 (미리 설치되어 있던 상태) |

## 과정

1. **아이디어** — 원장님이 원하는 것을 평소 말투로 적은 초안: [① 원 프롬프트](prompts/1-seed-prompt.md)
2. **프롬프트 다듬기** — ①을 AI에게 그대로 주고 "더 정확하고 세련되게 다듬어 달라"고 요청해, "규칙·개인정보 원칙·기능 범위·보안·디자인·진행 방식·검증 기준·문서·최종 보고" 순서로 구체화: [② 확장 프롬프트](prompts/2-expanded-prompt.md)
3. **한 번 입력** — 새 세션에 ②를 붙여 넣고 끝. 이후는 AI가 혼자 계획 → 개발 → 테스트 → 브라우저 확인 → 수정 → 문서화까지 진행

## 직접 따라 해 보려면

1. [Claude Code](https://claude.com/claude-code)를 설치하고, 빈 폴더에서 엽니다.
