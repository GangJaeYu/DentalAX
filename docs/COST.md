참고 사항 (공식 문서 기준)
- Claude Haiku 5.5는 한 번에 보내는 글이 10만 토큰을 넘으면 단가가 오릅니다(입력 $0.50/출력 $2.50). DentalAX 기능은 모두 이보다 훨씬 짧습니다.
- Claude 4.7 이후 모델은 같은 글을 약 30% 더 많은 토큰으로 셉니다(새 토크나이저). 아래 추정의 "보수적" 값에 반영했습니다.
- OpenAI GPT-6 계열과 Gemini는 답하기 전 "생각(reasoning)"에 쓴 토큰도 출력 요금으로 청구합니다. DentalAX는 OpenAI에 `reasoning_effort: low`를 기본으로 보내 생각 토큰을 줄입니다.
- 일괄 처리(Batch) API는 50% 할인되지만, 즉시 답이 필요한 원내 업무에는 쓰지 않았습니다.

적용한 가정

## 4. 추천 조합: Anthropic Claude (빠른 = Haiku 5.5, 상위 = Sonnet 5.5)

이유
1. **비용**: 짧은 글(공지·문자·리뷰)은 최저가 수준인 Haiku로, 품질이 중요한 문서 작성·회의록·도우미 답변은 Sonnet으로 나눠 월 수천 원대.
2. **한국어 문서 품질**: 공문·규정처럼 형식이 있는 긴 한국어 문서 작성에 강점이 있는 모델군입니다.
3. **데이터 정책**: API 입력을 기본적으로 학습에 쓰지 않고 30일 이내 삭제(아래 6절). 무료 등급이 학습에 쓰이는 Gemini보다 실수 위험이 적습니다.
4. **선불 크레딧 방식**이라 키가 새도 충전액 이상 청구되지 않습니다.

대안: 이미 OpenAI 계정이 있다면 GPT-6 Luna + GPT-6.1 Sol도 비슷한 가격·품질입니다. 비용을 최우선으로 하면 Gemini(반드시 **유료 등급**)도 좋지만, 2026-12~2027-01 가격 인상이 예정되어 있습니다.
최상위 모델(Opus, Astra, Argon)은 원내 업무에는 과합니다.

## 5. 비용 절약 팁

1. **기능별 저가 모델**: 관리 → AI 설정 → 기능별 모델 등급에서 "문서 작성"을 제외한 대부분을 "빠른"으로 두세요. 이미 기본값이 그렇게 되어 있습니다.
2. **원내 AI 도우미 데모 모드 활용**: 키가 없어도 관련 문단 검색은 무료로 됩니다. 단순히 "어디 적혀 있지?"를 찾을 때는 검색만으로 충분합니다.
3. **월 예산 한도**: 기본 3만 원, 80%에서 경고, 100%에서 차단. AI 회사 사이트에서도 사용 한도를 걸면 이중 안전장치가 됩니다.
4. **긴 문서는 나눠서**: AI 문서 다듬기는 전체 글을 보내므로, 긴 매뉴얼은 장별로 다듬으면 출력 토큰이 줄어듭니다.
5. **캐싱(참고)**: 같은 앞부분을 반복해 보내면 회사별 "캐시 입력" 단가(정가의 5~10%)가 적용될 수 있습니다. DentalAX의 기능별 지시문은 짧아(약 450토큰) 캐시 효과가 크지 않아 따로 켜지 않았습니다. 사용량이 많이 늘면 원내 AI 도우미의 고정 지시문 캐싱을 검토할 수 있습니다.
6. **환율·가격 갱신**: 분기마다 공식 가격 페이지를 확인해 가격표를 고치면 비용 표시가 정확해집니다.
