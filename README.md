# DentalAX — 치과 원내 업무 AI 도우미

> 코딩을 모르는 치과의사가 **Claude Code(Opus 5.5 · effort high)에 프롬프트 한 번**을 입력해,
> **사람의 결정·개입 없이 약 1시간 45분 만에** 완성된 원내 업무 웹 서비스입니다.
> 외부 플러그인·스킬·MCP는 하나도 쓰지 않았습니다. 원장님 누구나 원내 AX를 직접 시도해 볼 수 있다는 것을 보여 주는 예시 프로젝트입니다.

## 어떻게 만들었나

1. **아이디어** — 원하는 것을 평소 말투로 적었습니다 → [① 원 프롬프트](docs/prompts/1-seed-prompt.md)
2. **프롬프트 다듬기** — ①을 AI에게 "더 정확하고 세련되게 다듬어 달라"고 요청해 규칙·개인정보 원칙·기능·보안·디자인·검증 기준을 구체화했습니다 → [② 확장 프롬프트](docs/prompts/2-expanded-prompt.md)
3. **한 번 입력** — 새 세션에 ②를 붙여 넣은 뒤 AI가 혼자 계획 → 개발 → 테스트 → 브라우저 확인 → 수정 → 문서화까지 마쳤습니다.

| 걸린 시간 | 사람 개입 | 외부 플러그인 | 코드 | 검증 |
|---|---|---|---|---|
| 약 1시간 45분 | 0회 | 0개 | 약 38,400줄 (한국어 주석) | 자동 테스트 175개 · 브라우저 E2E 28단계 통과 |

시간표, 병렬 작업, AI가 스스로 찾아 고친 문제는 → [BUILD_STORY.md](docs/BUILD_STORY.md)

## 할 수 있는 일

| 영역 | 기능 | AI가 돕는 일 |
|---|---|---|
| 데스크 | 공지·인수인계(읽음 확인), 오픈·마감 체크리스트, 전화 응대 스크립트, 리뷰 답글, 안내 문자 템플릿 | 글 다듬기, 스크립트·답글·문구 초안, 의료광고 주의 표현 검사 |
| 재고·구매 | 입출고(유효기간 빠른 것부터), 부족·유효기간 알림, 거래처, 발주서 자동 작성·인쇄, 단가 변동, CSV | 거래명세서 → 입고 품목 인식, 발주 메시지 |
| 행정·서류 | 공문·안내문·규정·매뉴얼 작성과 A4 인쇄, 회의록, 서식 보관함 | 문서 초안·다듬기, 회의록 요약 |
| 인사·근무 | 근무표, 연차 신청·승인·잔여, 법정 교육 이수, 온보딩 | 온보딩 항목 제안 |
| 시설·법정 | 장비 점검 이력, 멸균기 기록(환자 정보 없음), 법정 정기 일정 | — |
| 운영 | 지출 기록·월별 요약 (환자 매출 제외) | 지출 분류 추천 |
| 원내 AI 도우미 | 원내 매뉴얼을 근거로 질문에 답하고 근거 문서 표시 | 근거 기반 답변 |
| 관리 | 사용자·권한, AI 설정·월 예산, 사용량·비용, 자동 백업·복원, 활동 기록 | — |

AI는 Claude · OpenAI · Gemini 중 고를 수 있고, **API 키가 없어도 데모 모드로 모든 기능을 써 볼 수 있습니다.** 예상 AI 비용은 월 몇천 원 수준입니다 → [COST.md](docs/COST.md)

## 빠른 시작 (Windows)

1. **Node.js LTS 설치** — https://nodejs.org/ko/download
2. **`install.bat`** 더블클릭 (처음 한 번)
3. **`start.bat`** 더블클릭 → 브라우저가 열리면 "처음 설정"에서 관리자 계정 만들기

직원 PC·태블릿은 검은 창에 나온 `http://192.168.x.x:3800` 주소로 접속합니다.
설치·접속·첫 설정·백업·업데이트·문제 해결은 → **[설치·사용 안내서 (GUIDE.md)](docs/GUIDE.md)**

## 원칙

- **환자 정보를 저장하지 않습니다.** 환자 이름·연락처·주민번호·차트번호·진료 내용을 넣는 칸이 없습니다.
- AI로 보내는 글은 서버가 먼저 검사해 주민번호·전화번호 등을 **가리거나 막습니다.**
- **원내 네트워크 전용**입니다. 인터넷에 공개하지 않습니다.
- API 키는 서버에만 암호화해 저장하고 직원 기기로 보내지 않습니다.

> 이 서비스는 업무 보조 도구이며 법률 자문을 대신하지 않습니다. 개인정보보호법·의료법(의료광고 등)·노무 관련 판단은 전문가와 상의하세요.
